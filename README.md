# Slotflow

Lightweight appointment scheduling for small businesses with Google Calendar and LINE integration.

Slotflow is designed first for a **single owner / single location** setup with an Android tablet as the fastest day-to-day interface.

## Initial direction

- Google Calendar as the operational calendar
- Android tablet dashboard / PWA for instant schedule visibility
- Google Apps Script backend where practical
- GitHub Pages / static frontend where practical
- LINE Official Account / Messaging API / LIFF for customer interaction
- Zero- or near-zero-cost infrastructure for the MVP
- Strong protection against double booking and calendar/data drift
